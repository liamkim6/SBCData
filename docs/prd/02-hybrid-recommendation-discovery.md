## 1. 배경

애드온 추천에 대해 다음 방향이 논의되었습니다.

> 소셜 추천과 콘텐츠 추천을 결합한다 — **비슷한 사용자들이 자주 선택하는 제품이면서 피부 타입 요건에도 맞는 제품**을 추천하면 발견(discovery)을 만들 수 있다. 그리고 그보다 성과가 더 좋은 것은 **"트렌딩" 제품**이며, 특히 **블렌딩(blend)** 했을 때 효과적이다. 이런 제품에는 **태그/라벨**을 붙여 사용자가 차이를 이해할 수 있게 한다.

즉 이번 실험의 추천 경험은 세 요소로 구성됩니다.

1. **개인화 하이브리드 추천** = 협업 필터링(유사 사용자의 선택) × 콘텐츠 필터(피부 타입·고민 적합성)
2. **트렌딩 추천** = 최근 전사적으로 인기가 급상승 중인 제품
3. **블렌딩 + 라벨링** = 두 소스를 한 지면에 섞어 노출하되, `🔥 지금 인기` / `✨ OO님 맞춤` 같은 라벨로 추천 이유를 투명하게 표시

## 2. 목표와 비목표

### 목표

1. 하이브리드 개인화 추천이 기존 추천(현행 로직) 대비 **추천 CTR·애드온 전환**을 개선하는지 검증
2. **트렌딩 블렌딩**이 개인화 단독 대비 추가 효과가 있는지 검증
3. 추천 유형 **라벨이 사용자 이해와 클릭 행동에 미치는 영향** 검증
4. 새로운 브랜드·카테고리 **발견율(Discovery Rate)** 개선

### 비목표

- 박스 본품 구성 로직 변경 (애드온 지면 한정)
- 실시간 학습/온라인 러닝 (일 배치 갱신으로 충분)
- 소셜 기능(팔로우, 리뷰 피드 등) 자체의 개발
- E1 리워드 플로우의 무료 애드온 선택 화면 (E1 실행 중에는 현행 로직 고정 — 개요 문서 §4)

## 3. 가설

| ID | 가설 | 검증 비교 |
|---|---|---|
| H1 | 하이브리드 개인화 추천은 현행 추천 대비 CTR·전환율이 높다. | C(현행) vs T1(하이브리드) |
| H2 | 트렌딩을 블렌딩하면 개인화 단독보다 CTR·전환율이 더 높다. | T1 vs T2(하이브리드+트렌딩 블렌딩+라벨) |
| H3 | 라벨은 추천 이유 이해를 도와 클릭 품질(클릭 후 전환)을 높인다. | T2 내 라벨 유형별 클릭 후 전환 비교 (탐색적) |
| H4 | 하이브리드 추천은 신규 브랜드 발견율을 높인다. | C vs T1, T2 |

## 4. 추천 로직 설계

### 4.1 후보 생성 (Candidate Generation)

**A. 소셜(협업 필터링) 소스**

- 입력: 애드온 조회·장바구니·구매 로그, 박스 커스터마이징 선택 로그 (E1의 `addon_selected` 데이터 포함)
- 방식(초안): item-based CF 또는 implicit-feedback matrix factorization(ALS). 콜드스타트 사용자는 피부 프로필 기반 유사 세그먼트의 인기 아이템으로 폴백
- 출력: 사용자별 후보 상위 N(예: 200) + 점수 `s_cf`

**B. 콘텐츠(피부 적합성) 필터/부스트**

- 입력: 사용자 피부 프로필(타입: 건성/지성/복합/민감, 고민: 트러블/미백/주름/모공 등, 알레르기·기피 성분), 제품 속성(카테고리, 성분, 적합 피부 타입, 효능 태그)
- 역할: **하드 필터**(기피 성분·명시적 부적합 제외) + **소프트 부스트**(적합도 점수 `s_content` 0~1)
- 하이브리드 점수: `s_personal = s_cf × (0.5 + 0.5 × s_content)` (부적합 후보는 사전 제거) — 계수는 오프라인 평가로 튜닝

**C. 트렌딩 소스**

- 산식(초안): 최근 7일 vs 이전 28일의 인기 가속도

  `trend_score = (조회 0.1 + 장바구니 0.3 + 구매 1.0 가중 합산)_최근7일 / (같은 가중 합산)_이전28일_일평균` — 신상품 편향 보정을 위해 최소 노출 임계치 적용
- 전사 공통 순위이되, 하드 필터(기피 성분·부적합)는 사용자별로 적용
- 갱신 주기: 일 1회 배치

### 4.2 블렌딩 정책 (T2)

- 지면 상위 K개 슬롯에 트렌딩 : 개인화 = **3 : 7** 비율로 인터리빙(초안, 상수로 두고 본 실험에서는 비율 자체를 실험하지 않음 — 비율 최적화는 후속 실험)
- 동일 상품이 양쪽 소스에 모두 있으면 개인화 슬롯을 차지하되 라벨은 두 개 모두 노출 가능(아래 §5)
- 트렌딩이지만 사용자에게 부적합(하드 필터 해당)한 상품은 해당 사용자에게 노출하지 않음 — "트렌드라서 보여주지만 맞지 않는" 경험 방지

### 4.3 랭킹·다양성

- 최종 정렬 후 카테고리 다양성 제약: 연속 동일 카테고리 최대 2개
- 품절·재고 부족 SKU 실시간 제외
- 응답 성능: 추천 API p95 < 300ms (사전 계산 + 캐시)

## 5. 태그/라벨 사양

라벨의 목적: **사용자가 "왜 이 제품이 나에게 보이는지"를 즉시 이해**하게 하여 신뢰와 클릭 품질을 높인다.

| 라벨 | 노출 조건 | 문구(초안) | 스타일 가이드 |
|---|---|---|---|
| 트렌딩 | trend_score 상위 & 트렌딩 슬롯 노출 | `🔥 지금 인기` | 강조색(브랜드 액센트), 카드 좌상단 |
| 맞춤 추천 | 개인화 슬롯 & s_content ≥ 임계치 | `✨ {닉네임}님 피부 맞춤` | 보조색, 카드 좌상단 |
| 유사 사용자 인기 | 개인화 슬롯 & CF 신호 강함 | `👥 비슷한 피부의 회원들이 선택` | 보조색 |
| 복합 | 트렌딩 + 맞춤 동시 충족 | `🔥 인기 · ✨ 맞춤` (최대 2개까지 병기) | 트렌딩 우선 배치 |

**라벨 원칙**

1. 카드당 라벨 최대 2개 — 과다 노출 시 라벨 신뢰도가 떨어진다.
2. 라벨은 **사실이어야 한다**: 트렌딩 라벨은 실제 trend_score 상위 상품에만, 맞춤 라벨은 실제 적합도 조건 충족 시에만. 마케팅 목적의 임의 부착 금지 (표시광고법 리스크 및 신뢰 훼손).
3. 라벨 탭 시 짧은 설명 툴팁 제공: "최근 7일간 구매가 급증한 제품이에요" 등.
4. 문구는 실험 시작 전 UX 라이팅 리뷰로 확정, 실험 중 변경 금지.

## 6. 실험 설계

### 6.1 그룹 구조 (3-arm)

| 그룹 | 비율 | 경험 |
|---|---|---|
| **C (대조군)** | 34% | 현행 추천 로직, 라벨 없음 |
| **T1 (하이브리드)** | 33% | 개인화 하이브리드 추천(§4.1 A+B), 맞춤/유사사용자 라벨 |
| **T2 (블렌딩)** | 33% | T1 + 트렌딩 3:7 블렌딩 + 트렌딩 라벨 |

- H1 = C vs T1, H2 = T1 vs T2. 라벨 단독 효과(H3)를 분리하려면 4-arm(라벨 없는 T2')이 필요하지만, 표본 부담을 고려해 본 실험에서는 T2 내 라벨 유형별 클릭 행동의 탐색적 분석으로 갈음합니다. 필요 시 후속 실험으로 분리 검증.
- **배정 단위/시점**: user_id 해시, 추천 지면(애드온 탐색 화면) 첫 진입 시 1회
- **다중 비교 보정**: 주요 비교 2건(H1, H2)에 대해 Bonferroni 보정 (α=0.025씩)

### 6.2 노출 지면

1. 애드온 스토어 메인 ("추천" 섹션)
2. 박스 커스터마이징 화면의 애드온 제안 영역 (단, E1 리워드 무료 선택 섹션은 제외)
3. 상품 상세 하단 "함께 보면 좋은 제품" (후속 — 본 실험 범위 밖, 오픈 이슈)

### 6.3 오프라인 사전 평가 (실험 전 게이트)

온라인 실험 전에 과거 로그 리플레이로 모델을 검증합니다. 통과 못 하면 온라인 실험을 시작하지 않습니다.

- 데이터: 최근 6개월 애드온 상호작용 로그 (+ E1 무료 애드온 선택 로그)
- 지표: Recall@20, NDCG@20 — 현행 로직 대비 개선 확인
- 콜드스타트 세그먼트(상호작용 < 3건) 별도 평가

## 8. 표본 크기와 기간

- 검정: 두 비율 z-검정, α=0.025(보정 후), 검정력 80%
- 예시: 기준 추천 경유 전환율 5%, 상대 +10%(→5.5%) 탐지 시 그룹당 약 **37,000 방문자**. 기준 8%면 그룹당 약 **22,000**
- 월간 추천 지면 방문자 수에 따라 기간 산출 (오픈 이슈). 최소 **2주**(요일 효과 2주기), 권장 **4주 + 1 결제 주기**(부착률 확인)
- 표본이 부족하면: primary를 CTR로 격상하거나, 3-arm을 2-arm(C vs T2)으로 축소하는 대안을 사전에 결정

## 10. 리스크와 완화

| 리스크 | 완화 |
|---|---|

| 피드백 루프(트렌딩이 트렌딩을 강화) | trend_score에 노출 보정(노출 대비 성과) 반영, 주기적 산식 점검 |
| 콜드스타트 품질 저하 | 세그먼트 폴백 + 오프라인 게이트에서 콜드스타트 별도 평가 |
| 라벨 남용으로 신뢰 훼손 | §5 라벨 원칙(사실성) 강제 — 라벨은 스코어 조건 충족 시 시스템이 자동 부착, 수동 부착 금지 |
| 민감성 피부 사용자에게 부적합 제품 노출 | 하드 필터를 후보 생성 단계에서 적용, QA 시나리오에 알레르기 프로필 포함 |
| E1과의 간섭 | E1 리워드 무료 선택 지면은 현행 로직 고정, 배정 직교성 유지 (개요 §4) |

## 11. 분석 계획

1. **주요 분석**: C vs T1 (H1), T1 vs T2 (H2) — Bonferroni 보정 z-검정, ITT

## 12. 롤아웃 / 의사결정

- **T2 승리**: 블렌딩+라벨을 기본 경험으로 100% 롤아웃 → 후속 실험: 블렌딩 비율(3:7 vs 5:5), 라벨 문구 최적화, 상품 상세 지면 확장
