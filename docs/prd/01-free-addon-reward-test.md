## 1. 배경

전면적인 보상(리워드) 체계를 도입하기 전에, 저비용·저리스크로 보상의 효과를 검증할 수 있는 선행 테스트가 필요합니다. 논의된 안은 다음과 같습니다.

> 첫 번째 박스를 받는 사용자에게 **다음 박스에서 애드온 상품 1개를 무료로 받을 수 있는 리워드**를 제공한다.

이 테스트가 우선순위로 합의된 이유:

- **리텐션 임팩트가 가장 큰 지점 공략**: 구독 커머스에서 이탈이 가장 큰 구간은 첫 박스 → 2번째 박스 전환이다. 무료 애드온은 2회차 결제를 유지할 명시적 이유를 만든다.
- **전면 보상 체계의 선행 신호**: 포인트/등급제 같은 전체 시스템을 만들기 전에, "보상이 실제로 재결제 행동을 바꾸는가"를 최소 기능으로 검증한다.
- **애드온 습관 형성**: 무료 경험으로 애드온이라는 구매 행동 자체를 학습시키면, 이후 유료 애드온 부착률 상승을 기대할 수 있다.
- **추천 실험(E2)과의 시너지**: 무료 애드온 선택 데이터는 추천 모델 학습·평가에 재사용된다.

## 2. 목표와 비목표

### 목표

1. 리워드 제공이 **M1→M2 결제 전환율**을 개선하는지 검증
2. 무료 애드온 경험이 **이후 유료 애드온 부착률**을 높이는지 검증
3. 리워드 1건당 비용(원가+물류) 대비 증분 매출로 **단위 경제성** 추정 → 전면 보상 체계의 예산 근거 마련

### 비목표

- 포인트 적립·등급제 등 전면 보상 체계의 설계 (본 테스트 결과 이후 별도 PRD → [PRD 03 — 리뷰 리워드 게이미피케이션](03-review-reward-gamification.md))
- 무료 애드온 선택 화면의 추천 로직 개선 (E2 범위 — 본 테스트에서는 기존 로직 고정)
- 기존 구독자(2박스 이상 수령자) 대상 리워드

## 3. 가설

| ID | 가설 | 검증 지표 |
|---|---|---|
| H1 | 첫 박스 결제자에게 다음 박스 무료 애드온 리워드를 주면 M1→M2 결제 전환율이 오른다. | M1→M2 전환율 (Primary) |
| H2 | 무료 애드온을 경험한 사용자는 3번째 박스에서 유료 애드온 부착률이 더 높다. | M3 유료 애드온 부착률 (Secondary) |
| H3 | 리워드로 인한 증분 매출(전환 개선 + 애드온 매출)이 리워드 비용을 상회한다. | 사용자당 증분 마진 (Secondary) |

## 4. 실험 설계

### 4.1 구조

```
첫 박스 결제 완료 (배정 트리거)
        │  user_id 해시 기반 랜덤 배정 (50:50)
        ├────────────────────────────┐
   [대조군 C]                    [실험군 T]
   기존 경험 그대로              첫 박스 배송 완료 시점에
        │                       "다음 박스 무료 애드온 1개" 리워드 지급
        │                            │ 지급 알림 (푸시/이메일/카카오)
        │                            │ 2번째 박스 커스터마이징 기간에
        │                            │ 무료 애드온 선택 UI 노출
        ▼                            ▼
   M2 결제 여부 ──────────── 비교 ── M2 결제 여부
   M2/M3 애드온 부착 ─────── 비교 ── M2/M3 애드온 부착 (무료분 제외)
```

- **배정 단위**: user_id (해시 기반, salt는 실험 코드 `E1_FREE_ADDON_REWARD`)
- **배정 시점**: 첫 박스 결제 완료 이벤트 발생 시 1회
- **배정 비율**: 대조군 50 : 실험군 50
- **노출 시점**: 리워드 지급 및 안내는 **첫 박스 배송 완료** 시점(제품 만족 경험 직후, 2번째 박스 결정 이전)
- **ITT 원칙**: 실험군 배정자가 리워드를 사용하지 않아도 실험군으로 분석

### 4.2 리워드 사양

| 항목 | 사양 |
|---|---|
| 리워드 내용 | 2번째 박스에 애드온 상품 1개 무료 추가 |
| 대상 SKU 풀 | 커머셜팀이 지정한 무료 애드온 풀 (원가 상한 ₩TBD 이하, 10~20개 SKU 권장) |
| 유효 기간 | 2번째 박스 커스터마이징 마감 시까지 (미사용 시 소멸, 이월 불가) |
| 사용 조건 | 2번째 박스 결제(구독 유지)가 전제 — 스킵/해지 시 사용 불가 |
| 중복 정책 | 계정당 1회, 재가입 사용자는 제외 (어뷰징 방지) |
| 소멸 안내 | 마감 72시간 전 미사용자에게 리마인드 1회 |

### 4.3 사용자 플로우 (실험군)

1. 첫 박스 배송 완료 → 리워드 지급 + 알림 발송: "다음 박스에서 원하는 상품 1개를 무료로 담아보세요 🎁"
2. 앱/웹 홈 및 마이페이지에 리워드 배너 노출 (만료일 카운트다운 포함)
3. 2번째 박스 커스터마이징 화면 진입 → 무료 애드온 선택 섹션 노출 (대상 SKU 풀, `무료` 라벨)
4. 선택 완료 → 주문 요약에 "무료 애드온 (리워드 적용)" 표기, 결제 금액 ₩0 처리
5. 미선택 상태로 마감 72시간 전 → 리마인드 알림
6. 2번째 박스 결제·배송 시 무료 애드온 동봉

## 5. 지표

| 구분 | 지표 | 정의 | 목표(초안) |
|---|---|---|---|
| **Primary** | M1→M2 결제 전환율 | 첫 박스 결제자 중 2번째 박스 결제자 비율 | 상대 +10% 이상 |
| Secondary | 리워드 사용률 | 실험군 중 무료 애드온을 실제 선택한 비율 | 40% 이상 (헬스체크) |
| Secondary | M3 유료 애드온 부착률 | 3번째 박스 결제 건 중 유료 애드온 포함 비율 | 대조군 대비 개선 |
| Secondary | 사용자당 증분 마진 | (전환·애드온 증분 매출 마진) − (리워드 원가+물류비) | > 0 |
| Guardrail | 해지율, 스킵률, CS 티켓 비율 | [공통 가드레일](../experiments/00-experiment-overview.md#23-가드레일-지표-모든-실험-공통) 참조 | 악화 없음 |
| Guardrail | 리워드 예산 소진 | 지급 리워드 원가 누계 | 사전 승인 예산 이내 |

> 리워드 사용률이 낮으면(< 20%) 효과 부재가 아니라 **인지 실패**일 수 있으므로, 사용률을 헬스체크 지표로 분리하고 알림 도달률·배너 노출률을 함께 봅니다.

## 7. 표본 크기와 기간

표본 크기는 기준 전환율에 따라 달라지므로 아래는 산식과 예시입니다. **실험 시작 전 데이터팀이 실제 기준치로 확정해야 합니다** (오픈 이슈).

- 검정: 두 비율 z-검정, 양측 α=0.05, 검정력 80%
- 예시: 기준 M1→M2 전환율 55%, 목표 상대 +10%(→60.5%) 탐지 시 그룹당 약 **1,300명**, 총 약 2,600명
- 기준 전환율 40%, 상대 +10%(→44%) 탐지 시 그룹당 약 **2,300명**

**기간**: `모집 기간(월간 신규 첫 박스 결제자 수 기준으로 산출) + 2 결제 주기(M2 결제 확인) + 1 결제 주기(H2의 M3 애드온 부착 확인)`. 예: 월 신규 3,000명이면 모집 약 1개월 + 관찰 2~3개월 = **총 3~4개월** (H1은 2개월 차에 1차 판독 가능).

## 8. 리스크와 완화

| 리스크 | 완화 |
|---|---|
| 무료 애드온 재고 소진/편중 | SKU 풀 10~20개로 분산, 재고 연동으로 품절 SKU 자동 제외 |
| 어뷰징(재가입 후 리워드 수령) | 계정당 1회, 재가입·중복 계정 탐지 시 발급 제외 |
| 대조군 사용자의 형평성 불만 (SNS 공유 등) | 안내 문구에 "일부 고객 대상 혜택" 명시, CS 대응 스크립트 준비, 실험 종료 후 전면 도입 시 소급 불필요함을 내부 합의 |
| 리워드가 전환이 아니라 '어차피 유지할 사용자'에게만 소비됨 | ITT 분석으로 증분만 측정, 세그먼트별(첫 박스 만족도, 가입 채널) 하위 분석 |
| 무료 애드온이 유료 애드온 매출을 잠식 (cannibalization) | M2 유료 애드온 부착률·매출을 별도 추적, 증분 마진 계산에 잠식분 반영 |
| 환불·부분취소 시 정산 복잡도 | R4 회수 규칙 + 무료 라인아이템은 환불 금액 계산에서 제외 |

## 9. 분석 계획

1. **1차 판독 (H1)**: 마지막 모집 코호트의 M2 결제 마감 + 7일 유예 후. 두 비율 z-검정.
2. **2차 판독 (H2, H3)**: M3 결제 마감 후. H3는 `(실험군 ARPU − 대조군 ARPU) × 마진율 − 리워드 단가 × 사용률`로 사용자당 증분 마진 추정.
3. **하위 분석 (탐색적)**: 가입 채널, 첫 박스 만족도(리뷰 점수), 피부 타입별. 사전 등록되지 않은 하위 분석은 참고용으로만 사용.
4. **SRM 체크**: 시작 48시간 내, 이후 주간.
