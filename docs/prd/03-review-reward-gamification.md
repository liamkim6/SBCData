## 1. 배경

[개요 문서 §5 의사결정 프레임](../experiments/00-experiment-overview.md#5-의사결정-프레임)의 "E1 성공 → 전면 보상 체계 설계 착수 (별도 PRD)"가 **바로 이 문서**입니다. PRD 01 §2 비목표에서 미뤄두었던 포인트 적립·등급제의 1차 구현이며, 그 첫 대상 행동을 **리뷰/피드백 작성**으로 정합니다.

왜 리뷰인가:

- **데이터 자산**: 리뷰(평점·텍스트·사진)는 E2 추천 모델(협업 필터링·콘텐츠 신호)과 커머셜 큐레이션의 원료 데이터입니다. Birchbox는 월 수만 건의 샘플 피드백을 수집해 브랜드 파트너용 B2B 데이터 상품으로 만들었습니다.
- **리텐션 상관**: 리뷰 작성은 제품 경험을 되짚는 행동으로, 작성자 코호트의 유지율 우위가 여러 커머스에서 보고됩니다(본 프로그램에서 자사 데이터로 검증 — §8).
- **구조적 소재 공급**: 구독 박스는 매달 4~6개 신제품 경험이 발생하므로 리뷰 소재가 끊기지 않습니다. 리뷰→포인트→애드온 사용→다음 박스 기대라는 **월 단위 습관 루프**를 만들 수 있습니다.

### 1.1 미국 시장 레퍼런스 벤치마크

리뷰·피드백에 리워드/게이미피케이션을 적용한 미국 서비스의 구조와 성과입니다. 공식 도움말로 확인된 수치와 보도/2차 출처 기준 수치를 구분해 표기합니다.

### 1.2 레퍼런스에서 도출한 설계 원칙

1. **이원 트랙**: 포인트(화폐성, 소멸 있음) ≠ 기여점수 XP(비화폐, 영구 누적). 두 원장을 분리한다 — Sephora + Local Guides 하이브리드.
2. **리뷰 1건의 화폐가치는 ₩300~500 수준에서 시작** — Ipsy(보수형)와 Birchbox(과잉형) 사이. 나중에 깎을 일이 없는 수준으로 출발한다.
3. **교환 리워드는 다음 박스 동봉**으로 물류 증분비 0 (Ipsy).
4. **품질을 배점에 내장**: 글자수·포토 가산, 별점만은 포인트 없음 (Local Guides).
5. **최상위 티어는 선정제 + 비금전·체험형 혜택** (Yelp Elite, Vine).
6. **대가성 리뷰 고지를 UI에 내장** (FTC / 공정위 추천·보증 심사지침).

## 2. 목표와 비목표

### 목표

1. **박스 리뷰 작성률**(배송 완료 14일 내 제품 리뷰 1건 이상 작성자 비율)과 **제품별 리뷰 커버리지**를 끌어올린다.
2. 적립 포인트의 애드온 사용을 통해 **애드온 부착률·애드온 ARPU**를 개선한다.
3. 리뷰 작성 습관 루프가 **M3+ 리텐션**에 기여하는지 코호트로 검증한다.
4. 리뷰 데이터(평점·텍스트·사진)를 **E2 추천·커머셜 큐레이션 자산**으로 적재한다.

### 비목표

- 구매액 기반 등급제(Sephora VIB식 지출 티어) — 본 프로그램 안정화 후 별도 검토
- 커뮤니티 피드·팔로우 기능 — Phase 3 시점에 별도 판단 (E2 PRD 비목표와 동일 기조)
- 외부 플랫폼(네이버, 올리브영 등) 리뷰 연동
- 포인트의 **구독료(박스) 할인 사용처** — 구독 매출 잠식 + 회계상 매출 차감 이슈로 제외, Phase 3 검토 항목으로만 유지
- E1 무료 애드온 리워드 구조의 변경 (§12 정합성 규칙 참조)

## 4. 포인트 경제 설계

### 4.1 사용처

| 사용처 | 내용 | Phase |
|---|---|---|
| 애드온 결제 차감 | 체크아웃에서 1P=₩1 차감, 최소 사용 1,000P | P1 |
| 포인트 숍 | 지정 SKU 무료 교환 (약 5,000P~), **E1 무료 애드온 SKU 풀 재사용**, **다음 박스 동봉 배송** (Ipsy 모델 — 물류 증분비 ≈ 0) | P2 |
| 구독료 할인 | **비목표** — Phase 3 검토 항목으로만 유지 | — |

### 4.2 유효기간·사용 조건

- 적립 후 **12개월 소멸** (Ipsy 동일). 소멸 30일 전 고지 (약관·CRM 의무).
- **사용은 활성 구독자만 가능**. 일시정지/해지 시 잔액 동결 → 재개 시 복원 (단, 소멸 시한은 계속 진행). 포인트를 리텐션 장치로 만드는 핵심 조건.

### 4.3 예산·부채 통제 (재무 협의 필수)

- 발행 포인트는 **부채(충당부채)로 인식** — 회계 처리 방식은 오픈 이슈(§13).
- 실질 원가 추정: `발행액 × 예상 사용률 × 사용처 원가율`. 애드온 원가율 ~40% 가정 시 풀가산 리뷰 1건(600P)의 실질 원가는 **₩120~240 수준**.
- breakage(미사용 소멸률) 가정은 보수적으로 시작하고 실측으로 갱신.
- **월 발행 총액 상한**과 초과 알림 설정. 발행/사용/소멸/부채 잔액 대시보드 주간 리포트 (E1 리워드 원가와 **통합 리워드 예산**으로 합산 관리).

### 4.4 배점 변경 가드레일 (Birchbox 교훈)

- 배점 하향·유효기간 단축은 원칙적으로 금지. 부득이한 변경은 **90일 사전 예고 + 기적립분 소급 없음**을 약관에 명문화.
- 이를 위해 초기 배점을 보수적으로 설정한다 (§1.2 원칙 2).

- 박스 커스터마이징 조기 오픈 (예: 12시간 선공개, Lv4+)
- 한정 SKU 우선 구매권 (Lv5+)
- **신제품 샘플 우선 체험** (Lv5+, Vine/VoxBox 모델 — 브랜드 제휴 시딩으로 원가 전가, 커머셜팀 협의)
- 인사이더 대상 오프라인 이벤트 (신제품 런칭·브랜드 클래스, Lv6)
- 레벨별 포인트 적립 가속(1.1~1.2x)은 부채 증가 요인이므로 **Phase 3 검토 항목**으로만.

## 6. 어뷰징 방지·검수 정책

### 6.1 지급 플로우

```
리뷰 제출 → 자동 필터 (동기) → 통과 시 즉시 적립 (즉각 피드백 유지)
                                   │
                                   └→ 사후 샘플링 검수 + 신고 접수
                                        └→ 위반 확정 시 포인트/XP 회수(REVOKE) + 리뷰 비공개
                                             반복 위반 시 프로그램 참여 제외
```

### 6.2 자동 필터 (적립 전)

- 최소 글자수·금칙어·이모지/특수문자 도배 패턴
- 동일 사용자 텍스트 유사도(복붙), 계정 간 중복 텍스트 탐지
- 이미지 중복 해시·스톡사진 탐지
- 도배 속도 제한 (예: 시간당 리뷰 수 상한)

### 6.3 한도·정책

- 계정당 월 적립 상한 (§3.2), 제품당 1회
- 재가입 계정은 포인트·XP·배지 **미승계** (E1 어뷰징 정책과 정합)
- **대가성 고지**: 포인트 적립 대상 리뷰에 "포인트 적립 리뷰" 라벨 표기 — 공정위 추천·보증 심사지침 준수 (문구는 법무 확인, §13)

## 7. 단계적 론칭 플랜

A/B 실험이 아닌 점진 롤아웃으로 진행하되, **미노출 코호트 비교 + 사전/사후(DiD)**로 효과를 추정합니다. 지표 정의는 [00-overview 공통 지표](../experiments/00-experiment-overview.md#2-공통-지표-체계)를 따릅니다.

| Phase | 범위 | 롤아웃 | 다음 단계 게이트 (초안) |
|---|---|---|---|
| **P0 준비** (~1개월) | 포인트 원장 구축, 회계 정책 확정, 배점 확정, 법무 검토, 리뷰 작성률 기준선 측정 | — | 재무·법무 승인 |
| **P1 MVP** (~2개월) | 제품 리뷰·박스 피드백 적립, 사용처 = 애드온 결제 차감, 리뷰 요청 CRM | 신규 가입자 → 전체 10% → 50% → 100% 점진 | 리뷰 작성률 기준선 대비 **상대 +50% 이상**, 포인트 사용률 ≥ 30%, 리뷰 반려율 < 10%, 발행 예산 내, 가드레일 무위반 |
| **P2 확장** (~3개월) | XP/레벨/배지, 포토·영상 가산, 포인트 숍(무료 애드온 교환·박스 동봉), 프로필 노출 | 전체 | Lv2+ 도달률 ≥ 25%, 포토 리뷰 비중·평균 글자수 유지 또는 상승, 리뷰 작성자 코호트의 M2 리텐션 우위 확인 |
| **P3 심화** (분기 단위) | 인사이더 선정제, 샘플 우선 체험, "도움돼요"·리뷰 노출(E2 지면 결합), 적립 가속 검토 | 전체 | P2 지표 유지 + 신고율·CS 티켓 정상 범위 |

- **중단 규칙**: 게이트 미달 시 다음 Phase 보류 및 재설계. 가드레일(§8) 위반 시 신규 적립 중지(기적립분은 유효기간까지 인정 — E1 중단 규칙과 동일 기조).

## 11. 분석 계획

1. **P1 판독**: 롤아웃 코호트(10%/50%) vs 미노출 코호트의 리뷰 작성률·포인트 사용률 비교 + 도입 전후 DiD. 게이트(§7) 판정.
2. **P2 판독**: 레벨 도달 분포, 포토 비중·글자수 추이, 리뷰 작성자 vs 미작성자 리텐션 코호트 분석 (가입월·박스 차수 통제).
3. **경제성 리뷰 (분기)**: 발행/사용/소멸/부채, 포인트 사용자 애드온 증분 매출로 실질 ROI 추정 — E1 원가와 통합 리워드 예산 리포트.
4. **품질 모니터링 (주간)**: 반려율, 평점 분포, 신고 건수.

## 12. E1/E2와의 정합성

1. **E1 FREE_ADDON 리워드는 쿠폰형(reward 엔티티)으로 존치**하고 포인트로 흡수하지 않는다. 무료 애드온 = 첫 박스 "온보딩 훅"(즉시성·단순함), 포인트 = "지속 습관 루프"로 역할을 분리한다. 포인트 원장은 신규 시스템으로 구축하며 E1 reward 테이블을 확장하지 않는다. 두 혜택의 원가는 통합 리워드 예산 대시보드에서 합산 관리한다.
2. **론칭 시점**: P1 롤아웃은 **E1 1차 판독(H1) 이후** 개시가 기본. 불가피하게 겹치면 E1 실험 코호트(실험군·대조군 모두)를 P1 점진 롤아웃 대상에서 제외한다 — 리뷰 리워드가 M1→M2 전환에 영향을 주면 E1 효과 측정이 오염되기 때문. ([00-overview §4](../experiments/00-experiment-overview.md#4-실행-로드맵과-상호작용-관리)에 반영)
3. **PRD 01과의 관계**: PRD 01 §2 비목표의 "포인트 적립·등급제 등 전면 보상 체계 (별도 PRD)"가 본 문서다 — 모순이 아닌 후속 관계.
4. **E2 시너지**: 리뷰(평점·텍스트)는 E2의 협업 필터링·콘텐츠 신호 및 오프라인 평가 데이터로 적재한다. E2 라벨 체계에 "⭐ 리뷰 평점 우수" 라벨을 추가하는 것은 E2 후속 실험 항목으로만 기재 (본 PRD 비목표).
