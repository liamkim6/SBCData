## 1. 전체 그림

구독 박스 비즈니스에서 우리가 개선하려는 핵심 퍼널은 다음과 같습니다.

```
가입 → 첫 박스 수령 → (리텐션 갈림길) → 2번째 박스 유지 → 애드온 구매 습관화 → 장기 구독 + 객단가(ARPU) 상승
          └─ 리뷰 작성 → 포인트 적립 → 애드온 사용 (월 단위 습관 루프, P3) ─┘
```

이번에 설계하는 트랙들은 이 퍼널의 서로 다른 지점을 공략합니다.

| 트랙 | 공략 지점 | 핵심 메커니즘 | 우선순위 |
|---|---|---|---|
| **E1. 무료 애드온 리워드 테스트** | 첫 박스 → 2번째 박스 전환 | 리워드(무료 애드온 1개)로 2회차 유지 동기 부여 + 애드온 경험 제공 | **1 (선행)** |
| **E2. 하이브리드 추천 & 트렌딩 라벨** | 애드온 탐색 → 구매 전환 | 소셜(유사 사용자) × 콘텐츠(피부 적합성) × 트렌딩 블렌딩 추천, 태그/라벨로 차별화 인지 | 2 |
| **P3. 리뷰 리워드 게이미피케이션** (실험 아님 — **단계적 론칭**) | 애드온 습관화 + 장기 리텐션 | 리뷰 → 포인트 적립 → 애드온 사용 루프 + 배지/레벨(비금전 인정) | 3 — E1 1차 판독 후 개시 |

### 두 실험의 관계

- **E1이 선행되어야 하는 이유**: E1은 전면적 보상 체계(리워드 프로그램) 도입 전의 저비용 선행 테스트입니다. 동시에 E1은 "무료 애드온을 고르는" 행동 데이터를 만들어내는데, 이 선택 데이터는 E2 추천 모델의 학습·평가 데이터로 재사용됩니다.
- **E2와의 접점**: E1 참여자가 무료 애드온을 고르는 화면이 곧 E2의 추천 지면입니다. 단, 두 실험의 효과가 섞이지 않도록 실험 배정을 직교(orthogonal)로 설계하거나, E1 분석이 끝난 뒤 E2를 시작하는 순차 실행을 기본으로 합니다(아래 §4 참고).

## 2. 공통 지표 체계

모든 실험 결과는 아래 공통 지표 정의를 따릅니다. 지표 정의가 실험마다 달라지면 비교가 불가능해지므로, 정의 변경 시 이 문서를 먼저 수정합니다.

### 2.1 북극성 지표 (North Star)

- **3개월 구독 유지율 (M3 Retention)**: 첫 박스 결제 후 3번째 박스까지 결제한 사용자 비율

### 2.2 주요 지표

| 지표 | 정의 | 주로 쓰는 실험 |
|---|---|---|
| M1→M2 전환율 | 첫 박스 결제자 중 2번째 박스 결제자 비율 | E1 |
| 애드온 부착률 (Add-on Attach Rate) | 박스 결제 건 중 유료 애드온 1개 이상 포함 비율 | E1, E2 |
| 애드온 ARPU | 사용자당 월 평균 애드온 매출 | E1, E2 |
| 추천 CTR | 추천 지면 노출 대비 상품 상세 클릭 비율 | E2 |
| 추천 경유 전환율 | 추천 클릭 후 애드온 장바구니 담기/구매 비율 | E2 |
| 신규 브랜드 발견율 (Discovery Rate) | 구매 애드온 중 사용자가 이전에 구매/보유한 적 없는 브랜드·카테고리 비율 | E2 |
| 박스 리뷰 작성률 | 배송 완료 후 14일 내 제품 리뷰 1건 이상 작성자 비율 | P3 |
| 포인트 사용률 | 발행 포인트 중 사용(REDEEM)된 비율 | P3 |

### 2.3 가드레일 지표 (모든 실험 공통)

실험군에서 아래 지표가 유의하게 악화되면 실험을 중단하거나 롤백합니다.

| 가드레일 | 악화 판단 기준(초안) |
|---|---|
| 구독 해지율 (churn) | 대조군 대비 상대 +10% 이상 악화 |
| 박스 스킵률 | 대조군 대비 상대 +10% 이상 악화 |
| 애드온 반품/불만 CS 티켓 비율 | 대조군 대비 절대 +2%p 이상 악화 |
| 앱/웹 추천 지면 로딩 p95 | 500ms 초과 (E2) |
| 무료 애드온으로 인한 단위 경제성(마진) | 사전에 합의한 리워드 예산 초과 (E1) |
| 포인트 발행 예산/부채 잔액 | 사전 승인한 월 발행 총액·부채 한도 초과 (P3) |
| 평점 분포 왜곡 (별점 인플레) | 도입 전후 평균 별점 +0.3★ 초과 상향 (P3) |

> 기준치는 초안입니다. 실험 시작 전 데이터팀과 함께 과거 분포를 확인해 확정합니다.

## 3. 공통 실험 원칙

1. **랜덤 배정 단위는 사용자(user_id)**: 박스 단위나 세션 단위 배정은 동일 사용자가 다른 경험을 하게 되어 오염됩니다.
2. **배정 시점 고정**: 배정은 실험별로 정의된 트리거 시점(E1: 첫 박스 결제 완료, E2: 추천 지면 첫 진입)에 1회 수행하고 이후 변경하지 않습니다.
3. **사전 등록(pre-registration)**: 가설, 주요 지표, 표본 크기, 분석 방법을 실험 시작 전에 PRD에 확정하고, 시작 후에는 변경하지 않습니다. 중간 엿보기(peeking)로 조기 종료하지 않습니다(가드레일 위반 제외).
4. **최소 실험 기간**: 구독 주기가 월 단위이므로, 결제 전환을 보는 실험은 최소 1개 결제 주기 + 유예 기간을 포함합니다.
5. **SRM 체크**: 실험 시작 후 48시간 내, 이후 주 1회 그룹 간 표본 비율 불일치(Sample Ratio Mismatch)를 확인합니다.
6. **분석 기준**: 이항 지표는 두 비율 z-검정(양측, α=0.05), 연속 지표는 t-검정 또는 Mann-Whitney를 기본으로 하고, 배정 기준의 ITT(intention-to-treat) 분석을 원칙으로 합니다.

## 4. 실행 로드맵과 상호작용 관리

```
2026-07        2026-08        2026-09        2026-10        2026-11        2026-12~
├─ E1 설계·구현 ─┤
        ├──────── E1 실험 실행 (2 결제 주기) ────────┤
                        ├─ E2 모델·라벨 구현 ─┤
                                      ├──────── E2 실험 실행 ────────┤
                ├─ E1 중간 리뷰   ├─ E1 최종 분석    ├─ E2 분석 → 전면 보상체계 + 추천 롤아웃 결정
                        ├─ P3 P0 준비(원장·회계·법무) ─┤
                                          ├─ E1 1차 판독 후 → P3 Phase 1 점진 롤아웃 → Phase 2/3
```

- **기본 방침(순차 실행)**: E2는 E1의 실행 기간과 겹쳐 시작할 수 있으나, E1 참여자(리워드 수령자)의 무료 애드온 선택 지면에는 E2 변형을 노출하지 않습니다. 즉 E1 리워드 플로우에서는 기존 추천 로직을 고정합니다.
- **동시 실행이 필요해질 경우**: 사용자 단위 직교 배정(E1 2그룹 × E2 3그룹 = 6셀)을 쓰되, 셀별 표본이 검정력을 충족하는지 재계산 후 진행합니다.
- E1의 무료 애드온 선택 로그(`addon_selected`, reward 플래그 포함)는 E2 오프라인 평가(리플레이)용 데이터셋으로 적재합니다.
- **P3(리뷰 리워드)와 E1의 간섭 규칙**: P3 Phase 1 롤아웃은 **E1 1차 판독(H1) 이후 개시**가 기본입니다. 불가피하게 겹치면 E1 실험 코호트(실험군·대조군 모두)를 P3 롤아웃 대상에서 제외합니다 — 리뷰 리워드가 M1→M2 전환에 영향을 주면 E1 효과 측정이 오염됩니다. 또한 P3 리뷰 요청 알림과 E1 리워드 알림의 발송 캘린더를 조정합니다(동일 주 중복 발송 금지). 상세는 [PRD 03 §12](../prd/03-review-reward-gamification.md#12-e1e2와의-정합성).
- P3의 리뷰 데이터(평점·텍스트)는 E2 추천 모델의 학습·평가 신호로 적재합니다.

## 5. 의사결정 프레임

| 시나리오 | 판단 |
|---|---|
| E1 성공 (M1→M2 전환 유의 개선, 마진 가드레일 통과) | 전면 보상 체계 설계 착수 → [PRD 03 — 리뷰 리워드 게이미피케이션](../prd/03-review-reward-gamification.md) Phase 1 개시 |
| E1 부분 성공 (전환 개선은 없으나 애드온 부착률·ARPU 개선) | 리워드를 리텐션 수단이 아닌 애드온 온보딩 수단으로 재포지셔닝 후 재실험 |
| E1 실패 (개선 없음 또는 가드레일 위반) | 전면 보상 체계 보류, 원인 분석(리워드 인지 부족? 애드온 매력 부족?) 후 재설계 |
| E2 성공 (추천 CTR·전환·발견율 개선) | 트렌딩 블렌딩 + 라벨을 기본 경험으로 롤아웃, 블렌딩 비율 최적화는 후속 실험 |
| E2에서 트렌딩 단독 우세 | 개인화 비중 축소, 트렌딩 큐레이션 운영 프로세스 수립 |

## 6. 오픈 이슈

- [ ] 월간 신규 첫 박스 결제자 수 확인 → E1 표본 크기·기간 확정 (PRD 01 §7)
- [ ] 추천 지면 MAU 및 현재 애드온 부착률 기준치 확인 → E2 표본 크기 확정 (PRD 02 §8)
- [ ] 무료 애드온 대상 SKU 풀과 원가 상한 확정 (커머셜팀)
- [ ] "트렌딩" 산식에 쓸 이벤트 로그(조회·장바구니·구매)의 수집 현황 점검 (데이터팀)
- [ ] 현재 리뷰 작성률·커버리지 기준선 측정 → P3 Phase 1 게이트 기준 확정 (데이터팀, PRD 03 §13)
- [ ] 포인트 회계 처리 방식(충당부채 인식·breakage 가정) 확정 (재무팀, PRD 03 §13)
- [ ] 대가성 리뷰 고지 문구·포인트 약관 법무 검토 (법무, PRD 03 §13)
